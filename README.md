# 🚗 Панель учета и мониторинга ТО (Changan CS55 Plus)

Интерактивное веб-приложение для контроля износа расходников, расчета стоимости обслуживания и автоматического отслеживания регламентов.

---

## ⚡ Быстрый запуск

### Вариант 1: Через Docker (рекомендуемый)
```bash
docker compose up --build -d
```
После запуска откройте в браузере: **[http://localhost:8080](http://localhost:8080)**

Остановка контейнера:
```bash
docker compose down
```

---

### Вариант 2: Локальный запуск без Docker (в 1 клик)
Просто дважды кликните по файлу:
📁 `run.bat`

Или через командную строку:
```bash
pip install -r requirements.txt
python app.py
```

---

## 📊 Возможности системы
1. **Интерактивные датчики износа:** цветная индикация ресурса для масла, фильтров, свечей, антифриза.
2. **Мгновенный расчет:** автоматический пересчет остатка ресурса при изменении текущего пробега и моточасов.
3. **Аналитика затрат:** графики распределения расходов по категориям и по этапам ТО (Chart.js).
4. **Журнал ТО:** фильтрация по категориям, поиск по артикулам и удобное добавление новых записей.
5. **Excel-файл:** синхронизация структуры данных с обновленным файлом `Учет_замены_расходников_авто.xlsx` на рабочем столе.
