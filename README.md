# 🚗 Панель учета и мониторинга ТО (Changan CS55 Plus)

Интерактивное веб-приложение для контроля износа расходников, расчета стоимости обслуживания и автоматического отслеживания регламентов.

---

## ⚡ Быстрый запуск

### Запуск через Docker Compose:
```bash
docker compose up -d --build
```
После запуска откройте в браузере: **[http://localhost:9595](http://localhost:9595)**

---

### ⚙️ Настройка порта (по умолчанию: 9595)
Если хотите изменить порт, отредактируйте файл `.env`:
```env
PORT=9595
```
Или передайте порт при запуске:
```bash
PORT=9090 docker compose up -d --build
```

---

### 🛑 Остановка контейнера:
```bash
docker compose down
```
