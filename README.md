Современное, легкое и полнофункциональное веб-приложение для контроля износа расходных материалов, регламентного обслуживания и финансовой аналитики автомобиля.

---

## 🌟 Ключевые возможности

### 1. 📊 Интерактивный дашборд и «Светофор» ресурса
* **Мониторинг износа в реальном времени:** Прогресс-бары остаточного ресурса для каждого узла (моторное масло, фильтры, свечи, охлаждающая и тормозная жидкости).
* **Цветовая индикация (Светофор):**
  * 🟢 **В норме:** Ресурс в порядке, запас хода более установленного порога.
  * 🟡 **Скоро замена:** Приближается регламентное обслуживание (осталось < 1 500 км или < 30 м/ч).
  * 🔴 **Замена!:** Ресурс исчерпан или просрочен.
* **Быстрое обновление показателей:** Ввод актуального пробега (км) и моточасов (м/ч) с мгновенным автоматическим пересчетом всех датчиков.
* **Аналитические KPI-карточки:**
  * Общая сумма затрат на обслуживание за всё время.
  * Стоимость 1 км пробега по расходникам.
  * Средняя скорость эксплуатации автомобиля (км/ч).

---

### 2. 🛠 Управление и редактирование событий ТО
* **Групповое ведение ТО (ТО-1, ТО-2, ТО-3, Внеплановое...):** Каждое обслуживание оформляется как единое событие с указанием даты, пробега и моточасов.
* **Редактирование ТО в 1 окне:** Возможность в одном модальном окне добавить/удалить любые детали, скорректировать цены, количество и артикулы.
* **Автоподсчет стоимости:** Автоматический расчет суммы всего ТО в процессе заполнения.

---

### 3. 📋 Детальный журнал расходников и запчастей
* **Мгновенный поиск:** Фильтрация по наименованию, марке/бренду (Лукойл, VIC, MANN, Changan) и артикулам деталей.
* **Фильтрация по категориям:** Двигатель, Фильтры, Зажигание, Охлаждение, Тормоза, Трансмиссия.
* **Прямые ссылки на покупки:** Кликабельные ссылки на товары (Ozon, Wildberries, Exist, Автодок, покупка у дилера).

---

### 4. ⚙️ Меню настроек и конфигуратор расходников
* **Индивидуальные регламенты:** Настройка интервалов замены в километрах и моточасах для каждой запчасти.
* **Настраиваемые пороги оповещения:** Установка индивидуального запаса предупреждения (за сколько км/часов включать желтый статус).
* **Справочник спецификаций:** Хранение рекомендованных производителем допусков (например: `SAE 0W-20 SP / C5 (4.2-4.5 л)`), артикулов и брендов.
* **Добавление собственных узлов:** Кнопка «Добавить расходник» позволяет поставить на мониторинг любые произвольные детали (тормозные колодки, ремни, аккумулятор и т.д.).

---

### 5. 🌓 Светлая и темная тема оформления
* Безупречный внешний вид в обоих режимах:
  * **Темная тема:** Глубокие оттенки Slate с неоновыми акцентами для ночного использования.
  * **Светлая тема:** Чистые белые плашки, мягкие тени и высокая контрастность для дневного света.
* Автоматическое сохранение выбранной темы в браузере (`localStorage`).

---

### 6. 📥 Экспорт в Excel (.xlsx) и бэкап JSON
* **Выгрузка в Excel в 1 клик:** Сервер на лету формирует полноценную книгу `.xlsx` со всеми листами (Дашборд, Журнал ТО, Справочник регламентов).
* **Резервное копирование:** Полная выгрузка базы данных в JSON через эндпоинт `/api/export-json`.

## 🚀 Быстрый старт (Развертывание на сервере)

### Вариант 1: Развертывание через Docker Compose (Рекомендуемый)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/scanek/car-maintenance-app.git
   cd car-maintenance-app
   ```

2. **Запустите контейнер:**
   ```bash
   docker compose up -d --build
   ```

3. **Откройте в браузере:**  
   👉 **`http://<IP-вашего-сервера>:9595`**

---

### Вариант 2: Локальный запуск на Windows (без Docker)
Просто дважды кликните по файлу **`run.bat`** в папке проекта, либо выполните:
```bash
pip install -r requirements.txt
python app.py
```

---

## ⚙️ Конфигурация порта

По умолчанию сервис работает на порту **`9595`**.  
Если вам требуется изменить порт на хосте, отредактируйте файл **`.env`**:

```env
PORT=9090
```

Либо укажите порт напрямую при старте контейнера:
```bash
PORT=9090 docker compose up -d
```

└── static/
    └── index.html          # Одностраничное приложение (Tailwind CSS, Chart.js, Lucide)

## 🛡 Сохранность данных

Все данные хранятся в файле `./data/db.json` и монтируются через Docker Volume (`./data:/app/data`).  
При обновлениях приложения через `git pull` и пересборке контейнеров **все ваши данные гарантированно сохраняются**.
